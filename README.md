# Titanic Dataset Analysis

This project uses the famous Titanic dataset to analyze passenger data and predict survival outcomes using machine learning techniques.

The dataset contains information such as passenger class, age, sex, fare, and family details.

The goal is to build a classification model that predicts whether a passenger survived the Titanic disaster or not.
